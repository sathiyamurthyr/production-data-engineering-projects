## 🎯 Overview

Distributed streaming platform with Kafka. This project covers producer/consumer patterns, topics, partitions, and stream processing fundamentals.

---

## 💼 Business Problem

Real-time data processing requires a reliable streaming platform that can handle high throughput, fault tolerance, and data retention for event-driven architectures.

---

## 💡 Solution

Implementation of:
- Kafka producer/consumer patterns
- Topic and partition design
- Consumer group management
- Schema registry integration
- Exactly-once semantics
