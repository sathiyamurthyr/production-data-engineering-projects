## 🎯 Overview

Compliance and security in data engineering. This project covers data lineage, access control, and regulatory compliance patterns.

---

## 💼 Business Problem

Organizations need to ensure data privacy, compliance with regulations (GDPR, CCPA), and maintain audit trails for data access.

---

## 💡 Solution

Implementation of:
- Data catalog and lineage
- Access control policies
- Data masking and anonymization
- Audit logging
- Compliance reporting
