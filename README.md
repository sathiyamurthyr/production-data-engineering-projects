## 🎯 Overview

This repository represents the official open-source portfolio for **Data Engineering Diaries** by Sathiya Murthy. It's designed to be one of the best Data Engineering repositories on GitHub, comparable to repositories maintained by Microsoft, Databricks, Netflix, Uber, Airbnb, Spotify, and Apache Foundation projects.

### Key Features

- ✅ **Production Ready** - Enterprise-grade code with proper error handling, logging, and monitoring
- ✅ **Beginner Friendly** - Step-by-step tutorials with detailed explanations
- ✅ **Well Documented** - Comprehensive documentation for every project
- ✅ **Highly Modular** - Reusable components and utilities
- ✅ **Easy to Extend** - Clean architecture with clear extension points
- ✅ **GitHub Showcase Quality** - Professional presentation and documentation
- ✅ **Recruiter Friendly** - Portfolio-ready projects with business context
- ✅ **Open Source Ready** - MIT licensed with contribution guidelines

## 🚀 Getting Started

### Prerequisites

- Python 3.13+
- Docker & Docker Compose
- Git
- Azure/AWS CLI (for cloud projects)
- Terraform CLI (for infrastructure projects)

### Quick Start

```bash
# Clone the repository
git clone https://github.com/sathiyamurthyr/production-data-engineering-projects.git
cd production-data-engineering-projects

# Create virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install development dependencies
pip install -r requirements.txt

# Install pre-commit hooks
pre-commit install

# Run tests
pytest tests/
```
